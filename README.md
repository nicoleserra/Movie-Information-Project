# Movie-Information-Project

## Overview

This Python application allows users to search for movie information using the OMDb (Open Movie Database) API. Users can search for a movie by title and retrieve details such as the release year, genre, runtime, directors, actors, IMDb rating and plot summary.

The application also stores previously searched movies in a text file (movies.txt) and allows users to view information for movies they have searched before.

## How the Program Works

The program sends requests to the OMDb API based on the movie title entered by the user. When a movie is found, its information is displayed and saved to a text file called movies.txt. The program also reads previously searched movies from the file, allowing users to look up movies they have searched before. A menu-driven interface and a continuous loop allow users to perform multiple searches until they choose to exit the application.
